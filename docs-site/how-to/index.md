# How-to guides

Task-oriented recipes. Each guide assumes you already have pilot running (see
the [Quickstart](../tutorials/quickstart.md)) and walks one real goal to
completion. Pick the one that matches what you need to do.

- **[Add a repo](add-a-repo.md)** — bring a repository's PRs and issues into the
  inbox, and filter by your role.
- **[Run an agent per workspace](run-an-agent-per-workspace.md)** — spawn Claude
  Code, Codex, or Cursor scoped to one task, including autonomous runs.
- **[Per-repo env and mounts](per-repo-env-and-mounts.md)** — inject environment
  variables, symlink shared directories, and materialize scripts into worktrees.
- **[Remote over SSH](remote-over-ssh.md)** — run the daemon on one machine and
  the TUI on another over a forwarded Unix socket.
- **[Mirror to Slack](mirror-to-slack.md)** — reflect your inbox into Slack
  channels.
