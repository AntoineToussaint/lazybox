Learning-oriented lessons. Each tutorial holds your hand from start to a single
guaranteed win — no branching, no options dumps. Once you have the feel for
lazybox, move on to the [How-to guides](/docs/how-to/) for specific tasks.

- **[Quickstart](/docs/tutorials/quickstart/)** — install lazybox (Homebrew,
  the `curl | sh` installer, or from source), open your first workspace, and
  send a reusable workflow to its agent in about five minutes.
