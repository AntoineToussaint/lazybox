Install the Mac preview

Use an Apple Silicon Mac running macOS 13.5 or later. The build needs Xcode Command Line Tools, Go, Node.js, Rust, and about 8 GB of free space.

git clone https://github.com/AntoineToussaint/lazybox.git
cd lazybox
make install

Open Lazybox, connect Claude Code or Codex, then press ⌘N to start a task.
